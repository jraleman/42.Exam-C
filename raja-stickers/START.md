# 🚀 Quick Start Guide

## To view the website:

### Option 1: Development Mode (Recommended for testing)
```bash
cd raja-stickers
npm run dev
```
Then open: http://localhost:3000

### Option 2: Production Mode
```bash
cd raja-stickers
npm run build
npm start
```
Then open: http://localhost:3000

### Option 3: Static Export (for hosting)
```bash
cd raja-stickers
npm run build
```
The static files will be in the `.next` folder and can be deployed to any hosting service.

## 📥 How to Download Stickers

1. Open the website in your browser
2. Browse through the sticker collection
3. Click on any category to filter (Green Boys, Ultra Eagles, etc.)
4. Click the "Download PDF" button on your favorite sticker
5. The PDF will download with 6 copies of the sticker ready to print!

## 🖨️ Printing Instructions

1. Open the downloaded PDF file
2. Use glossy sticker paper for best results
3. Print at 100% scale (no shrinking or enlarging)
4. Cut out the individual stickers
5. Stick them anywhere you want to show your Raja pride! 🦅💚
